# Adzan App 🕌🎵

Adzan App adalah aplikasi Android pemutar audio adzan dari berbagai negara yang dilengkapi dengan visual audio serta teks adzan Arab dan Latin yang sinkron dengan suara.

Aplikasi ini dibuat untuk memenuhi tugas mata kuliah Pemrograman Mobile II

---

## 📱 Fitur Utama

- Pemutar audio adzan
- Adzan dari beberapa negara:
  - Indonesia
  - Mekkah
  - Malaysia
- Teks adzan Arab & Latin (sinkron audio)
- Play, Pause, Stop (pause lanjut dari posisi terakhir)
- Audio Visualizer
- Tampilan bendera negara
- Minimum Android API 16 (Android 4.1)
